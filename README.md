# NRBFIT Fitness Studio

NRBFIT is a responsive, single-page website for a neighborhood fitness studio. It introduces the studio, shows the weekly class schedule, presents trainer profiles, and compares membership options.

## Site Sections

- **Hero:** Studio introduction, class-schedule link, and training highlights.
- **Class schedule:** Weekly classes with days, times, class types, and availability.
- **Coaches:** Nina Kim, Mae Rivera, and Andre Miles, presented with local portraits, specialties, profile details, and short bios.
- **Memberships:** Three pricing cards for drop-in, regular, and all-in plans.
- **Footer:** NRBFIT branding and contact link.

## Project Requirements

- A single page built with plain HTML5 and CSS3; no frameworks or build step.
- Responsive layouts for phone, tablet, and desktop, designed to avoid horizontal scrolling.
- Semantic page landmarks, one primary `h1`, and navigation links that target sections on the page.
- Global `box-sizing: border-box` and custom CSS variables for the color palette.
- Flexbox for linear layouts such as the header, hero, and action groups.
- CSS Grid for the class schedule, coach cards, pricing cards, and footer.
- Responsive breakpoints adapt the page layout and content for smaller screens.

## Run Locally

Open `index.html` in a browser. The coach portraits are stored in `assets/`. Google Fonts and the hero image are loaded from external sources and require an internet connection.
