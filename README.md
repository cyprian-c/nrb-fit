# NRBFIT Fitness Studio

NRBFIT is a responsive website for a Nairobi fitness studio. It presents the class schedule, coaching team, memberships, and studio enquiry options.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or serve that build with `npm run preview`.

## Project structure

- `src/components/` contains the page sections and reusable quantity stepper.
- `src/data/siteData.js` contains the hardcoded class, coach, and membership content.
- `assets/` contains the local studio hero and coach portraits, bundled by Vite.

The app uses React, Vite, and Tailwind CSS.
